# Роадмап

## Сделано

- Переход на Morpeh ECS, конфиги на трейтах, универсальный агент.
- Движение через конвейер скорости, камера от первого лица (Cinemachine) на оси капсулы.
- Даш: кулдаун, точная дистанция, направление по взгляду, неуязвимость.
- Бой: оружие-сущность, заряд, фазы атаки, попадание сферой → `DamageEvent`, оверлей оружия.
- Урон и смерть: `Health`, неуязвимость, `ActionBlockers`, `DestroyOnDeath`, перезапуск сцены при смерти игрока.
- Мир ECS принадлежит сцене, корректный перезапуск.
- Враги, расставленные на сцене (`AgentAuthoring`).
- ИИ: восприятие (конус, линия видимости, память), NavMesh-навигация, Utility AI с действиями Wander и Chase.
- Billboard для спрайтов.
- Капсулы агентов без трения — не прилипают к стенам.
- Фракции (`FactionDefinition`), фильтр урона по враждебности, цели восприятия по враждебности.
- Атака врага: действие Utility AI `Attack`, `AiAimSystem`, оружие врага с окном для даша; смерть игрока → перезапуск проверена в бою.

## Дальше

1. **Обратная связь при попадании** — красная вспышка экрана и полоска HP игрока, вспышка спрайта врага, отбрасывание (свой источник скорости).
2. **Жизнь оверлеев** — привязать оверлеи сцены к сцене (освобождать при выгрузке).
3. **Телеграф атаки врага** — визуальный сигнал замаха (смена спрайта или вспышка), чтобы окно для даша было читаемым.
4. **Агрессия в ответ** — `HostileOverride` для нейтральных существ.
5. **Буфер ввода** — атака и даш во время другого действия.
6. **Точки спавна игрока** — вместо `Vector3.zero`.
7. **Лут** — `SpawnOnDeathTrait`, лутаемый объект на месте тела.
8. **8-направленные спрайты** врагов по `FacingDirection`.
9. **Экран смерти** вместо мгновенного перезапуска.
10. **Патруль по точкам** — новое действие ИИ.
11. **Замедление при заряде атаки.**
12. **Сохранение состояния геймплея** (здоровье, позиция, убитые враги).

## Известные проблемы и техдолг

- `Position` не обновляется у сущностей без view.
- `WeaponPresentationSystem` публикует сообщение каждый кадр, даже в покое.
- Одно оружие на агента, смены оружия нет.
- Оверлеи живут вечно (создаются один раз на тип).
- Капсулы агентов без трения: на склонах агенты будут сползать. Нужна обработка земли, когда появятся склоны.

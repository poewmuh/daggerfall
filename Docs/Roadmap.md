# Роадмап

## Сделано

- Переход на Morpeh ECS, конфиги на трейтах, универсальный агент.
- Движение через конвейер скорости, камера от первого лица (Cinemachine) на оси капсулы.
- Даш: кулдаун, точная дистанция, направление по взгляду, неуязвимость.
- Бой: оружие-сущность, заряд, фазы атаки, попадание сферой → `DamageEvent`, оверлей оружия.
- Урон и смерть: `Health`, неуязвимость, `ActionBlockers`, `DestroyOnDeath`, перезапуск сцены при смерти игрока.
- Мир ECS принадлежит сцене, корректный перезапуск.
- Враги, расставленные на сцене (`AgentAuthoring`).
- ИИ: восприятие (конус, линия видимости, память), NavMesh-навигация, Utility AI с действиями Wander и Chase.
- Billboard для спрайтов.

## Известные проблемы и техдолг

- `Position` не обновляется у сущностей без view.
- Цели восприятия жёстко заданы через `PlayerControlled`.
- Маска попаданий оружия по слоям: враг не попадёт по игроку, пока не появятся фракции.
- `WeaponPresentationSystem` публикует сообщение каждый кадр, даже в покое.
- Одно оружие на агента, смены оружия нет.
- Оверлеи живут вечно (создаются один раз на тип).
- Капсулы агентов без трения: на склонах агенты будут сползать. Нужна обработка земли, когда появятся склоны.
